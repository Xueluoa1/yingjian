# LAN v0.1.3 contract

New application lives in server/ and public/, old ui/ remains a design prototype. Node >=22, Express ESM. Fresh data imports config/initial-sources.json once; history starts empty. No fabricated online devices or movies. All API JSON failures `{error: 'human readable'}`. Mutations require same-origin + `X-Yingjian: 1` header. Cookies are HttpOnly, SameSite=Lax. Server uses port 8080 by default.

- `GET /api/status` public: `{name,version,paired,role,device,addresses:[full HTTP origins],localAdminAvailable,passwordLoginAvailable,sourceCount,enabledSourceCount,uptime}`.
- `POST /api/auth/admin` `{password,name?}`: enabled when ADMIN_PASSWORD is configured; yields admin session cookie with rate limiting. PUBLIC_ORIGIN advertises a validated LAN origin for NAS/Docker mapped ports.
- `POST /api/auth/local-admin` `{name?:string}` loopback-only, yields admin session cookie, returns `{device,role}`. Dashboard explicitly activates via this on local computer.
- `POST /api/auth/logout` clears session.
- `POST /api/pairing` admin, optional `{origin}` chosen from server addresses; returns `{code,token,url,expiresAt,qrDataUrl}`. QR/link URL `/connect#pair=TOKEN` (opaque high entropy, one-use, expires10min). Six-digit code same pairing. Clear previous active pairing when regenerating.
- `POST /api/pairing/claim` public `{token? or code?,name,kind:'phone'|'tv'|'desktop'}` sets client cookie, registers device, returns `{device,role:'client'}`. Rate limit failure. Never auto-consume on GET.
- `POST /api/heartbeat` auth `{kind?,name?,playing?:{title,episode,id,sourceId,poster,position,duration,paused}}`, returns `{ok:true}`. Source name is resolved from saved sources; positions are bounded and posters must have a valid signed image URL. Online status from lastSeen within60s, no fake devices.
- `GET /api/overview` admin: `{sources,devices,activity,history,uptime,addresses,enabledSourceCount,sourceHealth,liveChannels}`.
- `GET /api/home-summary` auth: `{sourceHealth,liveChannels,settings}`. `sourceHealth` includes total/enabled/vod/enabledVod/live/enabledLive/measured/healthy/failed/unknown and nullable averageLatencyMs from successful probes of enabled sources. `liveChannels` contains cached count/loadedSources/totalSources/known; unknown channels must not be presented as a complete total.
- `GET /api/playback-settings` auth -> `{settings:{sourceId:'',autoNext:false}}`. `PATCH /api/playback-settings` accepts either or both fields; settings belong to the authenticated device. Empty sourceId browses all enabled VOD sources, otherwise the source must be enabled VOD. Deleting, disabling, or converting that source to live resets affected device selections to all enabled sources. Changing the source does not change other devices' browsing selection.
- `GET /api/devices` admin -> `{devices}`; `DELETE /api/devices/:id` revoke all device sessions (not own admin).
- `GET /api/sources` auth -> `{sources}`; each `{id,name,type:'vod'|'live',url,enabled,health?:{ok,latency,checkedAt,error}}`.
- `POST /api/sources` auth `{name,type,url}` -> `{source}`; `PATCH /api/sources/:id` auth fields; `DELETE /api/sources/:id` auth; `POST /api/sources/:id/probe` auth -> `{health}`. Paired devices can manage the shared household sources from playback settings. Device pairing/revocation and the management overview remain admin-only. Source mutations affect all devices. Name/enabled changes preserve last probe result; URL/type changes invalidate it. Probes measure API response latency, not streaming throughput; private upstream protection remains in force.
- `GET /api/catalog?category=all&year=&area=&genre=&sort=updated&page=1&pageSize=24` auth gathers enabled VOD sources allowed by the device's saved source selection. Categories: all/movie/series/anime/variety/short; sort: updated/score. Returns `{items,total,page,pageCount,pageSize,hasMore,facets:{years,areas,genres},failures,snapshot,canLoadMore,scope}`. Each source's item is a separate card, including when titles match across sources, with its own sourceId/sourceName/metadata/time. Facets filter the loaded snapshot, not the whole upstream library. refresh=1 rebuilds the first-page snapshot. `loadMore=1&snapshot=REV` expands one upstream page per source; up to 5 pages per source, 10 minute cache, concurrency 6 and 14 second round deadline. `scope` includes loadedCount/rawLoadedCount/sourceCount/successfulSources/complete/limited/updatedAt/expiresAt. Explicit `sourceId` selects an enabled VOD source with the same response/filter schema.
- `GET /api/search?q=...` supports the same category/facet/sort/page/loadMore parameters and response as catalog. Item `{id,sourceId,sourceName,title,poster,type,category,year,area,areas,genres,score,updatedAt,remarks,description?}`. score is a real source-provided number or null; updatedAt is ISO or null; missing values are not invented. Poster optional server authenticated image proxy URL (or empty).
- `GET /api/detail?sourceId=&id=` auth -> `{item,lines:[{name,episodes:[{name,url}]}]}`. Only HTTP(S) streams; sanitize descriptions to plain text.
- `GET /api/alternatives?sourceId=&id=` auth resolves a saved source item, searches a title with technical/language suffixes removed and returns `{groupKey,variants,failures}`. Only enabled saved sources; conservative same-title/year/category identity, season and edition preserved. Detail item also includes cached variants.
- `GET /api/live?sourceId=` auth -> `{channels:[{id,name,group,logo,url,sourceId}],failures}` parses enabled M3U source(s).
- `POST /api/playback` auth `{sourceId,id?,line?:0,episode?:0,channelId?}` -> `{url,directUrl,title,episodeName}`. Backend resolves episode/channel from saved source, produces signed same-origin proxy URL. No generic open proxy. Proxy rewrites HLS playlists incl relative segments, key/map/media URIs, passes Range/206; abort on disconnect; never bypass TLS.
- `GET /api/history` auth -> `{items}` shared household history, deduplicated by work while retaining the last selected source. PUT accepts category/year/type and recordedAt; late older saves from the same device are ignored to avoid overwriting progress after a source switch. Different devices use arrival order because their clocks may differ. `PUT /api/history` auth `{sourceId,id,title,poster,episodeName,line,episode,position,duration}` -> `{ok:true}`; clamp values, ignore invalid IDs, persist. `DELETE /api/history/:key` auth accepts the saved key or groupKey and removes that work's records.
- `GET /api/favorites` auth -> `{items}` shared household favorites, deduplicated by work and retaining the latest saved source. `POST /api/favorites` auth item; `DELETE /api/favorites/:key` auth accepts the saved key (`${sourceId}:${id}`) or groupKey and removes that work's favorites.

Frontend modes via `/?view=server`, `/?view=mobile`, `/?view=tv`. Film detail shows its source and episode choices without a source switcher. Player settings host same-work alternatives, with episode/time matching on switch. Main playback settings host browsing source selection, probes, CRUD and autoNext. Home/dashboard use actual source media, history, source health, device heartbeats and activity; no invented offline downloads, EPG, external chart metrics or remote control. `/connect` is the pairing page. If fragment token present, display connection info and confirm button before POST claim. Manual link UI accepts only HTTP(S) server origin, opens origin/connect in same tab with tv view hint as appropriate. Manual pairing after navigation uses6-digit code. System phone camera scanning works over LAN HTTP without web camera access. Native Android shell exposes QR scanning via its entry screen; website must not promise getUserMedia works on LAN HTTP.

Assets served locally: `/vendor/hls.min.js`, no external CDN needed. API server data dir env `DATA_DIR`, atomic JSON file backed storage. Export `createApp(options={dataDir,allowPrivateUpstream:false})` for tests; export `listen` or only start when direct invoked. Default source requests allow public HTTP(S), deny local/private metadata target; explicit `ALLOW_PRIVATE_SOURCES=1` supports trusted self-hosted LAN sources and test fixtures. DNS validation pinned using undici dispatcher to prevent rebinding; redirects validated per hop. Server rejects nonprivate client sockets, validates Host and Origin, no CORS wildcard. Signed playback proxy still requires session and scope. Local-admin requires socket loopback and same-origin custom header. Tests use ephemeral server and fixture.
