# 映间电脑播放器

双击 **映间播放器.html**，在浏览器中填写家里服务端的地址，例如 `192.168.1.100:8080`，或粘贴管理页复制的完整配对链接。

使用地址连接时，在打开的页面输入服务端生成的六位连接码；使用完整配对链接时确认连接即可。已连接后也可使用“上次使用”直接打开片库。

这是独立的浏览器播放入口，不启动后台服务，不需要 Node.js。电脑和家里的服务端需要处于同一局域网，服务端保持运行。服务端和播放器可以放在同一台电脑，地址使用 `127.0.0.1:8080`。

浏览器保存设备登录状态；入口只记住上次填写的服务地址，不保存连接码或配对令牌。更换浏览器后需要重新连接。也可将打开后的片库页面加入浏览器收藏。
