# 映间 · 局域网家庭影院首页 UI

这是保留的历史三端设计原型：服务端管理、安卓手机、安卓电视。此目录只有演示交互，不启动正式服务。正式 Web 界面位于 `public/`，服务端位于 `server/`，Android 工程位于 `android/`；使用方法见[项目 README](../README.md)。

## 预览

在此目录运行 `node serve.cjs`，浏览器访问 `http://127.0.0.1:4173`。也可直接打开 index.html（文件模式下复制和浏览器本地存储可能受限）。

- 服务端：`?view=server`
- 安卓手机：`?view=mobile`
- 安卓电视：`?view=tv`

支持切换首页、添加片源、启用/停用、演示影片搜索、选集、收藏、连接地址设置。电视支持方向键、Enter 和 Escape。所有影片与延迟、在线状态均为演示数据，源配置和收藏仅保存在本浏览器的 localStorage。

## 视觉方向

暂定名称「映间」。服务端采用深蓝侧栏、雾白内容区；观影端采用午夜蓝背景、柔和琥珀色操作按钮。主标题使用宋体类衬线字形，界面使用系统无衬线字体，地址使用等宽字形。无需外部字体或图片服务。

## 原创视觉素材

assets 下 4 张 PNG 均使用内置 image_gen 生成；不是实际影视封面。完整生成提示词见 assets/PROMPTS.md。
