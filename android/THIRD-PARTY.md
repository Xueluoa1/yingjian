# Android 第三方组件

- ZXing Core 3.5.3：本地二维码识别；项目 https://github.com/zxing/zxing ，许可证 Apache-2.0。
- ZXing JAR 位于 `app/libs/zxing-core-3.5.3.jar`。Apache-2.0 全文保留于 `app/src/main/assets/licenses/Apache-2.0.txt`，并随 APK 打包。
- Gradle Wrapper 属于 Gradle 项目，采用 Apache-2.0；https://github.com/gradle/gradle 。

客户端不打包影片、片源海报或远程网站内容。Android 系统 WebView 由设备系统提供，不包含在 APK 中。
